# 单元测试与覆盖率报告

## 一、测试命令

```bash
python -m unittest discover -s tests -v
```

项目共有 20 个单元测试，全部通过。

## 二、测试分类

| 测试目标 | 覆盖内容 |
|---|---|
| 相同文本 | 完全相同、全角空格和英文大小写差异 |
| 空文本 | 两篇同时为空、仅一篇为空 |
| 文本修改 | 插入、删除、替换和样例文本 |
| 文本差异 | 完全不同的文本、标点新增 |
| 算法函数 | 已知 LCS 结果的固定样例 |
| 命令行 | 正常路径、参数数量错误、输出路径等于输入路径 |
| 文件异常 | 文件不存在、无法解码、读取失败、写入失败 |
| 编码 | UTF-8 文件和 GB18030 文件 |
| 脚本入口 | 通过子进程执行 `main.py` |

## 三、覆盖率结果

使用 `coverage run --branch` 统计分支覆盖率，结果如下：

```text
Name                 Stmts   Miss Branch BrPart  Cover
------------------------------------------------------
main.py                 77      1     20      1    98%
tests/test_main.py     122      1      2      1    98%
------------------------------------------------------
TOTAL                  199      2     22      2    98%
```

主程序覆盖率为 `98%`。未统计的是子进程入口行，因为 coverage 默认不会
跟踪独立启动的子进程；该行已经通过实际命令行测试执行成功。

HTML 覆盖率报告位于 `htmlcov/index.html`，可通过浏览器打开并截图。
