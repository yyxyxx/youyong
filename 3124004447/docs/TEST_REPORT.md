# 单元测试与覆盖率报告

## 一、测试命令

```bash
python -m unittest discover -s tests -v
```

项目共有 29 个单元测试，全部通过。

## 二、测试分类

| 测试目标 | 覆盖内容 |
|---|---|
| 相同文本 | 完全相同、全角字符、英文大小写、空白和标点差异 |
| 空文本 | 两篇同时为空、仅一篇为空 |
| 文本修改 | 插入、删除、替换和题目示例 |
| HTML 提取 | GitHub blob 代码行、嵌套标签、空行和普通 HTML |
| HTML 过滤 | `script`、`style`、`noscript` 和无语义标签 |
| n-gram 算法 | 片段生成、非法长度、余弦相似度和零向量 |
| 命令行 | 正常路径、参数数量错误、输出路径等于输入路径 |
| 文件异常 | 文件不存在、无法解码、读取失败、写入失败 |
| 编码 | UTF-8 文件和 GB18030 文件 |
| 脚本入口 | 通过子进程执行 `main.py` |

## 三、覆盖率结果

使用 `coverage run --branch` 统计分支覆盖率：

```text
Name                 Stmts   Miss Branch BrPart  Cover
------------------------------------------------------
main.py                157      1     52      1    99%
tests/test_main.py     173      1      2      1    99%
------------------------------------------------------
TOTAL                  330      2     54      2    99%
```

主程序覆盖率为 `99%`。未统计的是 `if __name__ == "__main__"` 的子进程入口行，
该入口已经通过真实命令行和子进程测试执行成功。

HTML 覆盖率报告位于 `htmlcov/index.html`，可通过浏览器打开并截图。
