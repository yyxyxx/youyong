# 3124004447 个人项目：论文查重

## 运行方式

```bash
python main.py <原文文件绝对路径> <抄袭版论文绝对路径> <答案文件绝对路径>
```

答案文件输出保留两位小数的浮点型重复率。

## 算法

程序先进行 Unicode 规范化，忽略空白并统一英文大小写，然后使用最长公共子序列计算相似度：

```text
重复率 = 2 × 最长公共子序列长度 ÷ (原文长度 + 抄袭版长度)
```

动态规划使用滚动数组，空间复杂度为 `O(min(m, n))`。在作业给定的
500 字符规模下，耗时和内存占用均较小。
