# youyong

广东工业大学计科 24 级 78 班软件工程个人项目：论文查重。

## 项目目录

- `3124004447/`：学号目录
- `3124004447/main.py`：命令行程序入口
- `3124004447/tests/`：单元测试
- `3124004447/docs/`：设计、性能、测试和异常文档
- `3124004447/PSP.md`：PSP 开发记录

## 运行

```bash
cd 3124004447
python main.py <原文文件绝对路径> <抄袭版论文绝对路径> <答案文件绝对路径>
```

项目只依赖 Python 标准库。
